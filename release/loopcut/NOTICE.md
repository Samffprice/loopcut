# The Loopcut name and mark

The files in this folder are the Loopcut brand: the mark, the app icons and the splash. They are
in the repository so the product can be built from it.

"Loopcut" and the Loopcut mark identify this product. The GPL that covers this repository grants
rights in the code; it grants no right to use the name or the mark. A build made from a fork of
this repository must use its own name and icons, exactly as Loopcut does not use Blender's.

affiliated with or endorsed by the Blender Foundation.
